Projects

🦷 Kliniek Smile Enschede — AI Chatbot Demo

A fully working AI chatbot demo built for a fictional dental clinic. The bot answers patient questions in Dutch and English, walks users through booking appointments, collects leads when it can't help, and triggers instant email notifications to clinic staff — 24/7.

What it does:

  • AI-powered Q&A about services, pricing, and opening hours
  • Conversational appointment booking connected to a live database
  • Lead collection when the bot can't answer — no inquiry is ever lost
  • Instant email notifications on every booking and lead
  • Admin dashboard showing all bookings and leads in real time
  • Fully bilingual: Dutch and English, switches automatically

Tech: Node.js, Express, OpenAI API (GPT-4o-mini), SQLite, Resend, Railway, Vercel

🔧 Maintenance Manager System — Voortman Steel Machinery

During my 6-month internship at Voortman Steel Machinery (Sept 2025 – Feb 2026), I architected and built a cloud-based Maintenance Manager System to centralise preventive maintenance tracking for their global fleet of steel processing machinery.

  • RESTful backend built with ASP.NET Core (C#) using Clean Architecture and Repository Pattern
  • Multi-tenant PostgreSQL database with business reference architecture
  • Deployed on AWS EKS using Docker with a full CI/CD pipeline
  • Full CRUD, unit testing, and maintenance scheduling and tracking logic

Tech: ASP.NET Core, C#, PostgreSQL, Docker, AWS EKS, CI/CD
